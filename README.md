# Página web — Canales de comunicación en telecomunicaciones

## Qué incluye
- Navegación por secciones y mapa del sitio.
- Contenido sobre medios guiados y no guiados.
- Ilustraciones SVG creadas para la página.
- **Simulador interactivo de transmisión de datos** con 7 medios: par trenzado, coaxial, fibra óptica, radio, microondas, satélite e infrarrojo.
- Simulador con datos binarios editables, velocidad, interferencia, iniciar, pausar y reiniciar.
- Tabla comparativa.
- Multimedia: video educativo mediante enlace directo a YouTube + explicación de audio con Speech Synthesis del navegador.
- Preguntas de reflexión ética, ecológica, histórica, política y económica.
- Bibliografía con referencias en formato APA 7.
- Bloque para datos de integrantes, materia y tema.
- Flechas de navegación anterior/siguiente.

## Sobre el error 153 del video
El error 153 de YouTube puede aparecer cuando una página se abre directamente desde una ruta local (`file://`) y el reproductor embebido no recibe el contexto de referencia esperado. Para evitar que la página dependa del iframe, la versión actual muestra un reproductor visual y un botón **Abrir video en YouTube**. Al publicar la página en GitHub Pages también puedes volver a colocar un iframe si el profesor lo requiere.

## Cómo abrirla
1. Descomprime la carpeta.
2. Abre `index.html` con Chrome o Edge.
3. El simulador funciona localmente sin Internet.
4. El video y las referencias externas necesitan Internet.
5. El audio usa Speech Synthesis del navegador; no necesita un archivo `.mp3`.

## Antes de entregar
En `index.html`, busca el bloque **Identificación del equipo** y cambia:
- ESCRIBE AQUÍ EL NOMBRE
- ESCRIBE AQUÍ LA MATERIA
- cualquier dato adicional de tu equipo

## Publicarla con GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, `css/styles.css` y `js/script.js`.
3. En Settings → Pages, selecciona la rama principal y `/root`.
4. Abre la URL pública generada y pruébala desde el navegador.
